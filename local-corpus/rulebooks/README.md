# Rulebooks locais para QMD

Esta coleção contém extrações locais pesquisáveis de livros comerciais usados na campanha.
O texto integral fica em `extracted/`, que é ignorado pelo Git e nunca deve ser publicado.

O codex versionado guarda apenas metadados, decisões de mesa, material autoral e referências
de página. Cada arquivo extraído deve registrar o SHA-256 do PDF, páginas de origem e um link
para o conceito `Rulebook` correspondente em `codex/rulebooks/`.
