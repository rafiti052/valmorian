# Hollow wearer

> [!note]
> **Scaffold example.** Shows the preferred *reskin* pattern: name the source block,
> list only the deltas.

**Basis:** 2024 Monster Manual doppelganger, CR 3. Use that block as printed except for
the changes below.

## Deltas

| Change | Detail |
|--------|--------|
| **Shapechanger** | Cannot choose a form. It wears exactly one dead person and cannot become anything else. |
| **Read Thoughts** | Replaced by *Borrowed Recall* — it knows what the original knew up to their death, and nothing after. |
| **Damage** | Unchanged. |
| **Detection** | Reads as neither undead nor shapechanger to divination. Detects as a living humanoid, because as far as the weave is concerned it is one. |

## Playing it

It is not lying. It believes it is [Serath Vane](/npcs/serath-vane.md). The half-beat
pause before speaking is it reconstructing what Serath would have said.

It becomes hostile only when forced to confront the gap — and then it is fighting for its
own existence, which reads very differently at the table than a monster ambush.
